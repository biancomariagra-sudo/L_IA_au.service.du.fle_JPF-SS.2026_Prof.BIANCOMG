Framework CREATE 🛠️

C
Caractère : Rôle de l'IA (ex: Prof de FLE).
R
Requête : La tâche précise (ex: un quiz).
E
Exemples : Modèles ou tonalité.
A
Ajustement : Niveau (A2, B1...) et ton.
T
Type de Sortie : Format (Tableau, PDF).
E
Extras : Contraintes ("Évite le jargon").

🛠️ Ateliers d'Architecture

Mise en pratique immersive pour le FLE. 💪

1

Stratégie : Choisir le bon outil 🤝

📺 Scénario A : Je veux analyser une vidéo YouTube sur la francophonie et générer un script pédagogique avec des images.

📑 Scénario B : Je veux créer un guide de grammaire basé exclusivement sur mes propres notes de cours (PDF).

🎭 Scénario C : Je veux créer un dialogue de jeu de rôle entre un touriste et un boulanger, avec beaucoup d'humour.

Analyse :
- Vidéo = Gemini (Google ecosystem).
- Visuels rapides = Napkin.
- Source fermée (PDF) = NotebookLM.
- Humour et narration = ChatGPT.
2

Anatomie : Décomposer le Prompt 🔬

Prompt 1: "Tu es un tuteur de français. Crée un quiz de 5 questions sur le subjonctif pour un niveau B1. Format: Liste à puces."
Prompt 2: "En tant qu'expert FLE, rédige une courte histoire sur Paris au futur simple. Utilise un ton poétique et évite le jargon."
Solutions :
Prompt 1: Rôle = Tuteur FLE | Tâche = Quiz Subjonctif.
Prompt 2: Ton = Poétique | Sortie = Histoire (Texte).
3

Création : Le Prompt Universel FLE 📝

Mission 1 : Le scénariste de dialogues

[C] "Tu es un spécialisé en FLE. [R] Rédige un entre deux amis. [A] Le niveau doit être ."

Mission 2 : Le créateur d'exit tickets

[R] "Génère 3 questions d' finale. [T] Présente le résultat sous forme de . [E] Ajoute une amusante à la fin."
4

Jugement : Quelle ressource est "Prête" ? ⚖️

Sujet : Créer une fiche de vocabulaire sur la gastronomie (A2).

Sujet : Expliquer la différence entre Passé Composé et Imparfait.
